i. Nama Aplikasi :QuizApp (Aplikasi Kuis Pilihan Ganda)

ii. Deskripsi singkat Aplikasi:QuizApp adalah aplikasi kuis interaktif berbasis mobile yang dibangun menggunakan framework Flutter. Aplikasi ini dirancang untuk menyajikan kuis pilihan ganda secara praktis dan responsif, memungkinkan pengguna untuk menguji pengetahuan mereka melalui antarmuka yang bersih dan mudah digunakan. Aplikasi mengelola alur pertanyaan secara otomatis mulai dari penyajian soal, pencatatan jawaban, hingga perhitungan dan penayangan skor akhir.

iii. Fitur-fitur yang tersedia:
Halaman Utama (Home Screen): Menampilkan judul kuis, deskripsi singkat, dan tombol navigasi utama untuk memulai kuis.

Sistem Kuis Pilihan Ganda (Quiz Screen): Menampilkan pertanyaan beserta opsi jawaban pilihan ganda, indikator nomor soal, dan navigasi otomatis ke soal berikutnya.

Perhitungan Skor Dinamis: Sistem secara otomatis mencatat pilihan pengguna dan menghitung skor berdasarkan jawaban yang benar.

Halaman Hasil & Ringkasan (Result Screen): Menampilkan skor akhir pengguna setelah menyelesaikan seluruh pertanyaan kuis.

Reset / Ulang Kuis (Restart Quiz): Fitur untuk mengulang kuis dari awal sehingga pengguna bisa mencoba kembali kuis yang sama.

c. Dokumentasi:
i. Credit ke sumber-sumber aset yang digunakan:Atribut Visual & Ikonografi:

Lucide / Feather / Google Material Icons: Digunakan untuk ikon antarmuka pengguna (UI Icons) pada navigasi, tombol, dan indikator soal.

Google Fonts (Urbanist): Pustaka tipografi utama yang digunakan untuk tata letak teks dan antarmuka aplikasi.

Framework & Package Flutter (Dependencies):

Flutter SDK: Framework UI buatan Google untuk pengembangan aplikasi cross-platform.

google_fonts: Package untuk integrasi tipografi Google Fonts secara dinamis.

flutter_svg: Package pendukung untuk rendering berkas gambar bertipe SVG (Scalable Vector Graphics).
